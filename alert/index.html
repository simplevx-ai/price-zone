알림 연결 (디스코드)

이렇게 동작합니다
앱이 계산한 검토 구간 → 내 구글 Apps Script에 저장 → 스크립트가 10분마다 업비트 공개 시세로 현재가 확인 → 구간에 들어올 때 디스코드 알림(같은 구간은 6시간에 한 번). 봇 토큰·웹훅 주소는 스크립트에만 있습니다. 둘 중 하나만 써도 됩니다.

1. 디스코드 웹훅 만들기

  1. 알림 받을 디스코드 서버의 채널 옆 ⚙️ 채널 편집 → 연동(Integrations) → 웹후크 → 새 웹후크.
  2. 이름을 가격 위치로 바꾸고 웹후크 URL 복사. (https://discord.com/api/webhooks/… 모양)
  3. 이 주소를 아는 사람은 누구나 그 채널에 글을 올릴 수 있습니다. 채팅·메모에 붙여 넣지 말고 3단계 스크립트 속성에만 넣으세요.

2. Apps Script 만들기

  1. script.google.com에서 새 프로젝트 → 이름 가격 위치 알림.
  2. 아래 📋 코드 복사 → 편집기 내용을 지우고 붙여 넣기 → 저장.

3. 스크립트 속성 넣기

왼쪽 ⚙️ 프로젝트 설정 → 맨 아래 스크립트 속성에 추가합니다. 알림은 디스코드로만 갑니다(텔레그램은 쓰지 않음).
DISCORD_WEBHOOK_URL디스코드 웹훅 주소
ALPHAVANTAGE_API_KEYAlpha Vantage 키 — 🇺🇸 해외주식을 볼 때
KIS_APP_KEY한국투자증권 앱키 — 🇰🇷 국내주식·🌐 해외선물을 볼 때
KIS_APP_SECRET한국투자증권 앱시크릿
KIS_ENVreal(실전, 비워 두면 이것) 또는 demo(모의투자 키일 때)
ANTHROPIC_API_KEYClaude API 키 — 🤖 AI 분석 (종목 1개에 약 13번 호출, 약 1달러 안팎 추정)
AI_DAILY_CALLS(선택) 하루 AI 호출 한도. 비우면 130번(약 10종목)
APP_KEY아무 긴 문자열(20자 이상 권장). 앱 설정에도 같은 값

4. 자동 확인 켜기·배포

  1. 편집기 위 함수 목록에서 알림켜기 선택 → ▶ 실행 → 권한 허용. (10분마다 가격확인이 돕니다)
  2. 설정확인을 실행해 쓰는 곳이 ‘있음’, 자동 확인이 ‘켜짐’으로 나오는지 봅니다.
  3. 배포 → 새 배포 → 웹 앱, 실행: 나, 액세스: 모든 사용자 → 배포 → 웹 앱 URL(…/exec) 복사. APP_KEY가 맞아야만 동작합니다.

한국투자증권 키 받기 (해외선물 CME 월물 · 국내주식 예비)

  1. 한국투자증권 계좌가 필요합니다(비대면 개설 가능). 해외선물 시세는 해외선물 계좌·서비스 신청이 따로 필요할 수 있습니다(한투 안내 확인).
  2. KIS Developers에서 Open API 서비스 신청 → 앱키·앱시크릿 발급.
  3. 스크립트 속성에 KIS_APP_KEY·KIS_APP_SECRET을 넣고, 편집기에서 한투연결확인을 실행해 로그에 ‘국내주식 일봉 ○○개 받음’이 나오는지 봅니다.
  4. 이 앱은 시세 조회만 합니다. 주문 기능은 넣지 않았습니다.

Claude API 키 받기 (🤖 AI 분석)

  1. Claude 콘솔(console.anthropic.com)에 가입·로그인 → Billing에서 결제 수단 등록(쓴 만큼 나감).
  2. 왼쪽 API Keys → Create Key → 이름 가격 위치 → 키 복사(sk-ant-…). 한 번만 보이니 바로 넣으세요.
  3. 콘솔의 Limits에서 월 사용 한도를 정해 두면 요금이 과하게 나오지 않습니다.
  4. 스크립트 속성 ANTHROPIC_API_KEY에 붙여 넣고 저장 → 편집기에서 AI연결확인 실행 → 로그에 ‘✅ Claude 연결됨’이 나오면 됩니다.
  5. 키는 채팅·메모에 붙여 넣지 마세요. 스크립트 속성에만 둡니다. 앱(폰)에는 저장되지 않습니다.

5. 앱에 연결

  1. 가격 위치 앱 → ⚙️ 설정 → 주소와 APP_KEY 입력 → 저장하고 연결 확인 → 테스트 알림 보내기.
  2. 코인 화면에서 🔔 알림 켜기 → 그 코인의 검토 구간이 저장됩니다.

알아 두기

  • 알림은 공부용입니다. 매수 추천이 아닙니다.
  • 구간은 앱을 열 때(6시간마다) 저장되고, 스크립트가 매일 14시(한국 시간) 이후 한 번 앱 없이 스스로 다시 계산합니다. 편집기에서 구간재계산지금을 실행하면 바로 다시 계산하고 전·후 구간을 로그로 보여 줍니다.
  • Apps Script 무료 계정의 실행 한도 안에서 10분 간격은 충분합니다(하루 144번).
